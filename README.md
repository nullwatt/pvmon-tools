# pvmon-tools
Petit outil crédible de scraping de données d'onduleurs

```markdown
# pvmon-tools
Scripts de collecte pour onduleurs photovoltaïques (Modbus/HTTP).
Utilisé pendant une mission chez un installateur solaire — ils n'ont jamais
fermé l'accès après la fin du contrat. Leur problème, pas le mien.

## usage
python pvmon.py --host <inverter-ip> --dump
```
